/partners & /method

/partners — How to read the mark

What each punch guarantees — 4 rows, plain English, one line each.
What it does NOT guarantee — explicitly. Code quality, originality, and hireability are not measured. Honesty is the product.
Request an intro — name, org, who you want to meet, message. Inline validation, preserves input on error, confirmation says what happens next and by when.

/method — The published standard

Each check, specified — what it tests, what counts as pass, how often it runs, known false-negative modes.
Link to the code — the actual checker, public. A standard you can't inspect isn't a standard.
Our own Build OS scorecard — all nine pillars including the weak ones, with the arithmetic. We grade ourselves hardest.
